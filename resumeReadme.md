# Charles Babbage Resume Website

## HTML Tags & Attributes Used

- `<!DOCTYPE html>` → Declares the document type as HTML5.  
  Ensures the browser interprets the file as hypertext, not plain text.  

- `<html lang="en">` → Root element that wraps all HTML content.  
  `lang="en"` specifies the document language as English.  

- `<head>` → Contains metadata, title, and page settings.  
  It is not displayed directly on the webpage.  

- `<meta charset="UTF-8">` → Sets character encoding to UTF-8.  
  Supports all characters including symbols and international text.  

- `<meta name="viewport" content="width=device-width, initial-scale=1.0">` → Defines how the page is displayed on devices.  
  `width=device-width` matches screen width, `initial-scale=1.0` sets default zoom.  

- `<title>` → Defines the title of the webpage.  
  Appears in the browser tab and search engine results.  

- `<body>` → Contains all visible content of the webpage.  
  Everything inside `<body>` is rendered on screen.  

- `<header>` → Introductory section at the top of the page.  
  Typically includes name, tagline, or navigation.  

- `<h1>, <h2>, <h3>` → Heading tags for titles and subtitles.  
  `<h1>` is the main heading, `<h2>` for sections, `<h3>` for sub-sections.  

- `<p>` → Defines a paragraph of text.  
  Used for descriptions and general content.  

- `<hr>` → Inserts a horizontal line.  
  Visually separates different sections of the page.  

- `<section>` → Groups related content into blocks.  
  Helps organize resume parts like About, Skills, Projects.  

- `<ul>` → Creates an unordered (bulleted) list.  
  `<li>` defines each item in the list.  

- `<table>` → Displays data in rows and columns.  
  `border="1"` adds visible lines around cells.  

- `<thead>` → Defines the header section of a table.  
  `<th>` inside it represents column titles.  

- `<tbody>` → Defines the body section of a table.  
  `<td>` inside it represents individual data cells.  

- `<strong>` → Emphasizes text by making it bold.  
  Used to highlight important information.  

- `&copy;` → HTML entity for the copyright symbol.
